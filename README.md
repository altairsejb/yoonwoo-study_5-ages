# 오늘의 실험

만 5세 아이가 하루 한 장씩 하는 과학 실험 카드 앱입니다. 실험은 화면 안에서 물건을 끌어서 합니다. 아이패드 사파리에서 열고 홈 화면에 추가해 쓰며, 가로로 놓고 쓰는 것이 좋습니다.

## 깃허브에 올리기

1. 깃허브에서 새 저장소를 Public으로 만듭니다. (예: `today-experiment`)
2. Add file → Upload files 에서 이 폴더의 파일을 모두 올리고 Commit 합니다.
3. Settings → Pages → Branch 를 `main` / `(root)` 로 고르고 Save 합니다.
4. 1~2분 뒤 `https://내아이디.github.io/today-experiment/` 주소가 열립니다.
5. 아이패드 사파리로 그 주소를 열고, 공유 버튼 → 홈 화면에 추가를 누릅니다.

## 고치기

- 실험 카드는 `index.html` 안의 `CARDS` 목록이고, 카드마다 `sim`이 어떤 실험 무대를 쓸지 정합니다. 무대는 `SIM.tank`, `SIM.ramp`처럼 13종이 있습니다.
- 파일을 고쳐 다시 올린 뒤에는 `sw.js` 맨 위의 `v2`를 `v3`으로 올려야 아이패드에 새 버전이 반영됩니다.
- 기록은 아이패드 안에만 저장됩니다. 앱을 지우면 기록도 사라집니다.
